# Repository guide

Before editing code, read [CONTRIBUTING.md](CONTRIBUTING.md) for naming, imports,
runtime boundaries, verification, and Git conventions. When adding an app,
package, or moving responsibility, also read [ARCHITECTURE.md](ARCHITECTURE.md).

For web changes, follow `apps/web/AGENTS.md` and the installed Next.js docs.
For MCP configuration or onboarding, consult `apps/mcp/README.md`.

Run `pnpm check` before committing. Report any check that could not run and keep
existing user changes intact.
